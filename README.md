# Nobami — Windows releases

This repository only hosts **signed release builds** of the Nobami desktop app (Windows installer and portable zip)
and the update metadata (`latest.yml`) that the app's built-in updater reads.

- Website & web app: https://nobami.com
- Download page: https://nobami.com/ko/download/ · https://nobami.com/en/download/
- Latest release: https://github.com/work517/nobami-releases/releases/latest
- Contact: projectteamforyou@gmail.com

Source code is not published here. Each release lists SHA-256 checksums (`SHA256SUMS.txt`);
installers are code-signed by Projectteamforyou (프로젝트팀포유).
